---
description: Start a new task with a clear brief
agent: think
---

Start a new task.

Do not solve it immediately.

First determine whether the current workspace is a software/project repository or a general context.

Collect only the missing information needed to create a task brief.

Ask iteratively for:

1. Goal — what are we trying to achieve?
2. Domain/context — what project or life/work domain does this belong to?
3. Constraints — what restrictions, existing decisions, or relevant context matter?
4. Success criteria — how will we know the task is complete?

Infer answers from the current repository or conversation when they are already clear instead of asking redundantly.

After collecting enough information:

- Summarize the task brief.
- Identify whether shared knowledge or skills may be relevant.
- Do not implement anything yet.
- Recommend whether the next step should remain in THINK, move to PLAN, or proceed directly to BUILD.
