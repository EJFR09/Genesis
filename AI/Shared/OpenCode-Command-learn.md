description: Extract reusable knowledge from completed work
agent: think

Review the work completed in the current context and identify knowledge worth preserving.

Do not save anything immediately.

Classify each useful finding as one of:

- Project-specific → keep in the repository.
- Reusable procedure → candidate Skill.
- Reusable starting structure → candidate Template.
- Reusable technical knowledge → Knowledge.
- Operational procedure → Runbook.
- Reusable lesson from experience → Lesson.
- Not valuable enough to preserve → discard.

For every reusable candidate:

1. Give it a concise name.
2. Explain why it is reusable.
3. Suggest the target domain and path in the shared knowledge base.
4. Remove project-specific noise and sensitive information.
5. Show the distilled content.

Ask for approval before writing or modifying the shared knowledge base.
