# Bootstrap Project

Use this skill when initializing or formalizing a new project.

## Workflow

1. Understand the project brief before creating files.
2. Identify the project domain and technology.
3. Inspect available shared templates and skills.
4. Select only resources relevant to this project.
5. Adapt templates instead of copying them blindly.
6. Create or update the repository `AGENTS.md`.
7. Create project-specific documentation such as:
   - README
   - specs
   - architecture notes
   - ADRs when needed
8. Copy only relevant reusable skills into `.opencode/skills/`.
9. Treat copied resources as project-specific instances from that point onward.
10. Verify the resulting repository structure with the user before implementation begins.

Do not copy the entire shared knowledge base into a repository.
